# Miles to KM Converter 🚗➡️📏

A straightforward, beginner-friendly desktop application built with Python and Tkinter that converts miles into kilometers.

## Features

- **Intuitive GUI:** Built using Tkinter's clean grid layout system.
- **Accurate Conversion:** Multiplies input values by the standard unit factor (`1.609344`).
- **Clean Interface:** Styled with customized fonts, colors, and structured padding for a clear view.

## Requirements

- Python 3.x
- `tkinter` (included by default in most standard Python installations)
